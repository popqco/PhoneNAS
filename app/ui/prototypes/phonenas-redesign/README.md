# PhoneNAS UI 原型（一次性设计稿，非正式功能）

**问题：多文件夹镜像进入日常使用后，哪种界面结构更清楚？**

3 个布局共用同一份模拟任务，在同一页面通过 `?variant=A|B|C` 切换。现有应用是 PySide6 桌面程序、没有网页路由，因此把独立网页原型放在 `app/ui/prototypes/`，不修改桌面程序入口或打包配置。

## 打开

从仓库目录运行：

```powershell
python app/ui/prototypes/phonenas-redesign/serve.py
```

访问 <http://127.0.0.1:8766/?variant=A>。只监听本机回环地址，仅提供本目录中的静态原型文件；按 Ctrl+C 停止。也可以直接双击 `index.html`，不需要安装依赖。

## 对比

| 方案 | 地址参数 | 结构 | 适用 |
| --- | --- | --- | --- |
| A 清爽工作台（推荐） | `?variant=A` | 侧边导航、任务卡片、设备与活动侧栏 | 日常使用，几到十几个文件夹 |
| B 文件夹映射 | `?variant=B` | 文件夹列表、来源 → 镜像、独立历史去向 | 看懂一个任务的流向，逐项管理 |
| C 紧凑控制台 | `?variant=C` | 图标导航、紧凑任务表、批量操作、执行记录 | 管理较多文件夹 |

用底部浮动条或键盘 ← / → 切换。输入框获得焦点时不会拦截方向键。切换保持模拟状态；刷新页面重置。

## 可以体验

- 添加单个文件夹、批量添加示例文件夹。
- 编辑每个任务的来源/远端路径、频率、保留天数、排除预设。
- 检查空路径、重复来源及远端目录重叠的提示。
- 暂停任务、模拟同步、串行排队；C 支持多选。
- 按任务查看旧文件历史、体验恢复提示。
- 切换到概览、活动、设置页面。
- 底部代码图标查看完整相关内存状态；每次切换方案也输出到浏览器控制台。

## 边界

- 所有连接、大小、文件数、时间、预演差异和历史内容都是演示数据；不代表当前系统状态。
- 不读取真实配置/密码，不访问 WebDAV，不启动 PhoneNAS 或 rclone，不挂载盘符，不读写真实同步文件。
- 无数据库、localStorage、外部字体、CDN、第三方脚本或远端请求。
- 表单校验只服务于原型体验，不是正式版的完整路径/文件安全实现。
- 这是浏览器中的视觉与交互稿，不代表未来改用 Web 技术。确定方向后，重新实现为 PySide6 控件，继续使用现有 rclone/WinFsp。
- 尚未选定方案，未提交、推送、打包或发布。原型不纳入现有 PyInstaller datas。
