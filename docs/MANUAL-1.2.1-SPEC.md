# PhoneNAS 1.2.1：本机手动上传/下载

## 用户确认的目标

在同一台电脑使用同一本地 LefeetHardware 和手机镜像，手动选择上传或下载。不建立互相冲突的重复任务，不自动双向。用户已授权补齐功能、更新本机安装、配置仅手动，并且只在重新验证两端相同后建立控制基线，不覆盖/删除/传输工作文件。

## 必须满足

1. `auto_sync` 与任务 `enabled` 独立，旧配置缺失字段默认 true。仅手动设置持久保存并跨重启有效，不进入自动排队，无下次自动计划。手动请求、串行占用仍可用；停用仍禁止执行。
2. 同一卡片两个直接入口：上传到手机、下载到本地。两者先只读查看差异，接受确认后重新核对再执行，保留既有内容冲突、历史及取消保护。
3. 不通过改变任务方向、伪造最后成功、复制任务或放宽路径隔离来实现手动双向。
4. 新增单独的首次基线预览/初始化接口。只接受两个已有目录的实际内容完全一致；确认绑定任务/连接/范围、两端摘要和当前控制状态。执行在数据集锁内重检；不一致、锁占用、中断、旧基线冲突或确认后变化即拒绝。
5. 初始化只能写手机 `.phonenas` 控制信息和本机实际内容基线。不得调用普通同步、payload mkdir/copy/move/delete、历史清理，不伪称完成传输。远端已 ready 且一致时复用批次，不重复发布。
6. 本机最终保留 `D:\LefeetHardware`、手机 `backup/lefeethardware/mirror`、手机历史 `backup/lefeethardware/versions`、既有本地历史根，设置启用且仅手动。密码、挂载、自启偏好保留。
7. 构建、回归、审查后更新 `D:\Program Files\PhoneNAS` 至1.2.1，核验配置之后启动。无 Git提交/推送/Release，无PC手机保活服务，无实际文件同步。

## 验证接口

Config/MirrorTask 保存和兼容；TaskQueue 自动/手动分离；Qt 卡片和编辑器启用/仅手动及两个意图；Main preview/confirmation/serialclaim；SyncEngine 基线初始化在临时alias中的同内容/变化/异常拒绝及无payload写入。最后完整回归、隔离预览、包smoke及真实安装配置验收。
