# PhoneNAS 1.2 工作台与两地接力

## 用户场景

公司电脑主要更新文件并上传手机，家里电脑主要接收，偶尔编辑后交回。用户不主动两端同时编辑。保留 A 清爽工作台，不引入后台自动双向同步。

## 必须满足

1. 修复卡片状态裁切、搜索图标、原始日志刷卡、陈旧完成状态、活动 UUID、无效按钮、跳过向导计划启动、频率静默钳制和键盘/长路径/缩放布局。
2. 每任务明确上传发布或下载接收；接收必须绑定已存在的手机数据集，不创建新空远端。
3. 上传旧文件保留在手机；下载/公司接收更新的旧文件保留在本地独立历史根。历史不是完整快照。
4. 内容基线须使用文件内容身份，不能用时间、大小、数量或差异分类标记代替。配置导入、连接/方向/路径/范围变更后不能沿用旧授权。
5. 家里本地新增/修改/删除未交回时停止拉取。手动交回必须先展示差异，确认后新扫描；手机自共同基线变化则拒绝覆盖。
6. 家里交回后，公司旧副本自动上传必须被阻止；公司本地未修改时可以明确接收手机更新，两边都变时不自动合并。
7. 数据集级读写互斥，发布中/失败内容不得作为已完成数据。WebDAV 不是完整目录原子快照；外部工具/可写挂载绕过锁时只能检测和阻止，不能宣称绝对一致性。
8. 取消不承诺回滚，不推进成功基线/清理历史。中断写入保存意图和所有权证明，只能原电脑明确核对后续作，不自动强夺锁。
9. 保留缺失/异常空来源、大量删除、首次接管保护；恶意远端路径、大小写/Unicode/文件目录冲突、链接/重解析点不能绕过本地写入隔离。
10. 暂停自动计划与取消当前操作分开；未知总量忙碌，已知传输进度须来自真实统计。
11. v1/v2 迁移只改变内存配置结构，首次保存前留原始字节备份；不自动反转、搬移或删除现有任务的数据。
12. 本轮仅隔离测试与本地构建。不得修改真实配置或手机数据，不覆盖安装、不启动正式同步、不提交推送或发布 GitHub，不加 PC 手机服务监控。

## 验证接口

- Config/任务公开接口：结构迁移、身份失效与隔离。
- SyncEngine/Worker 接口：临时 alias remote 下完整接力、冲突、异常来源、中断、同大小时间内容变化、确认后变化。
- HistoryService/LocalHistoryService：任务限定列举/独占恢复/删除与恶意路径。
- 原生 Qt 页面/窗口/对话框：隔离 UI 回归和 Windows 实际视觉检查；安全模式不得挂载、触达真实配置或执行真实同步。
