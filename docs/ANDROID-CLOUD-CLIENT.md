# PhoneNAS 云盘 · Android 客户端

在访问云盘的手机安装 `com.phonenas.client`。存放文件的手机使用独立的[文件服务端](ANDROID-USER-GUIDE.md)。客户端不是托管服务，也不提供后台自动同步或 Windows 盘符。

## 配对

1. 两台手机使用官方 Tailscale，存放文件的手机为选定 VPN 地址启用 PhoneNAS HTTPS `18889`。客户端不连接明文 HTTP，不降级到局域网、代理或错误证书。
2. 在「文件 → 连接云盘」填入固定 Tailscale IPv4 或对应 HTTPS 地址。导入服务端从首页导出的**公开**证书，对照服务端页面输入 SHA-256 指纹；不要安装到系统信任根，不要传私钥。
3. 只在手机客户端输入云盘账号和密码。密码默认遮挡，可点按显示；重配只预填公开身份和用户名，密码须重输。登录与保存是两步；需要记住时，在「连接」点保存到本机，连接由 Android Keystore 加密。移除本机连接不改云盘文件。

旧 WsgiDAV 的 HTTP `8888` 不是该 HTTPS 入口。不要为让旧 `X:` 兼容而关闭 TLS、改旧服务或把生产控制目录当互传共享。

## 文件操作

- 可浏览所有可读共享。「下载到手机」核对完整长度后发布到「下载 → PhoneNAS」，本地同名不覆盖。「另存为」通过系统选择器，先完整暂存，最多 512 MiB；第三方提供者写入失败可能留下部分目标。
- 上传前先在「连接 → 互传位置」选独立普通读写共享，不能选镜像、历史、控制目录或其上级。在所选共享内可多选最多 50 个文件。原件不删除；同名默认跳过，明确勾选后才尝试另名副本。若显示「待核对」，先刷新，应用不会自动重传。
- 传输由用户从前台发起；连接中断不会自动续传。未知大小上传需要独立暂存，最多 512 MiB。可完成的实际大小还受两端空间、服务端超时和网络速度限制。

构建方式见 [Android 维护说明](../android/README.md)，历史结果与未验场景见[验收记录](ANDROID-ACCEPTANCE.md)。
