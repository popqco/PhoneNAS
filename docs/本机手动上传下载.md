# 这台电脑如何使用 LefeetHardware

## 已配置的路径

- 电脑工作目录：`D:\LefeetHardware`
- 手机当前镜像：`backup/lefeethardware/mirror`
- 手机旧文件历史：`backup/lefeethardware/versions`
- 本地旧文件历史：`D:\LefeetHardware.PhoneNAS-history-104807c6`
- 任务模式：启用、仅手动。重启软件不会定时执行。

## 平时只用两个按钮

### 在电脑改好了，要放到手机

点任务卡上的 **上传到手机** → 等待内容和差异校验 → 核对新增/更新/删除 → 确认。

### 手机上有公司电脑的新文件，要拿到这台电脑

点任务卡上的 **下载到本地** → 等待内容和差异校验 → 核对新增/更新/删除 → 确认。

软件不会在点击按钮的瞬间就覆盖文件。若两端从共同基线起都改过、或者有未完成的操作，会阻止直接覆盖；不要为此反复改方向、删除基线或新建相反任务。

## 如何理解进度（1.2.2）

- “下载到暂存区”先准备并校验变化文件，明确注明“尚未写入目标”；本阶段到 100% 时，接收目录可能仍为空。
- “复核来源／目标内容”表示仍在确认内容没有变化，不是卡在传输 100%。无服务器哈希时会读取文件，可能持续数分钟；界面显示该阶段已用时，不伪造百分比或剩余时间。
- “写入本地接收目录”才开始应用已确认的修改。它的 100% 仍只是复制阶段结束，后面还有旧文件保留、目录核对和最终校验。
- 只有任务明确显示“拉取完成／上传完成”，才表示内容验证、保存结果和锁释放均已结束。不要因某个阶段到 100% 就关闭软件或再次点击执行。
- 不需要在上传后清空本地，也不需要为了再次接收清空文件夹。现有内容保护规则未变；本地有未交回修改时仍会停止直接覆盖。

## 为什么只有一张任务卡

同一本地目录和手机镜像是一对映射，在这一张卡上手动选方向即可。两条独立相反任务容易互相覆盖，因此仍保留重复映射保护。

## 其他说明

- 不用为了每次上传/下载修改“任务用途”。
- 不要点“继续自动计划”来实现手动同步；仅手动模式本身不会进入自动计划。
- 历史文件页可选本地或手机历史，恢复到新目录，避免覆盖当前工作文件。
- 上传或下载中的删除表示把目标端旧文件移入历史，不是双向冲突合并；确认前仍应核对。
- 首次共同基线初始化只写控制信息，不等于执行过一次上传/下载；因此“尚未完成首次同步”不代表路径配置丢失。
