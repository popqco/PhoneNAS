# PhoneNAS 1.2.2 阶段进度修复

## 背景与边界

1.2.1 在暂存复制到 100% 后没有及时切换提示，远端复核期间目标可以仍为空；写入后的目录循环也会留下陈旧百分比。本次下载实际已成功，用户明确要求修复进度问题，并批准构建及更新 D 盘安装。

本次不改变手动方向、基线冲突保护、手机目录布局、自动计划或历史保留策略；不自动发起真实同步，不修改手机服务，不创建 PC 保活任务，不提交／推送或发布 GitHub Release。

## 行为约定

- `SyncProgress` 是不可变阶段事件：阶段、说明、可选字节数／处理数量。仅暂存和写入复制阶段依据真实字节统计显示“本阶段”百分比。
- `SyncEngine` 保留文字回调，新增结构化回调；`SyncWorker` 保留文字信号，新增阶段事件信号。界面不从提示文字猜测百分比。
- 明确显示核对、暂存（尚未写入目标）、暂存校验、两端复核、写入目标、旧文件保留、目录核对、最终内容校验、保存结果、历史收尾和释放锁。
- 每次复制退出立即清除其百分比，每次阻塞校验前先发出忙碌阶段。界面在工作线程忙碌时更新阶段已用时，不伪造已处理数量、速度、剩余时间或总体百分比。
- 只有原有完整成功信号允许显示任务完成。取消、失败、保护和预览终态清除旧进度、停止耗时更新，延迟进度不能恢复已经结束的状态。
- 目录补齐复用已验证的目标目录及成功复制文件的父目录，按需建立缺失目录。保留空目录、排除规则、逐项取消与本地无链接检查，并在最终内容清单中验证来源目录存在。
- 不删除或跳过原有完整 SHA256 复核，不以时间、大小、旧缓存、计数代替内容身份。

## 公开验证接口

1. `SyncEngine.preview/execute` 与回调：真实临时 alias remote，暂存后阻塞远端 hashsum 时目标为空且进度为复核；放行后完整验证，包含历史、空目录、排除和确认后变化。
2. `SyncWorker` 真实 QThread 信号：阶段与文字兼容、成功不提前、失败和取消没有成功，线程实际结束后回收。
3. Qt 窗口／卡片：隔离配置、`operational=False`，阶段百分比立即重置、耗时持续更新、卡片／状态栏／总览一致、终态不被陈旧事件覆盖。
4. 目录性能：确定性命令计数与本地样本耗时，不设易波动的性能硬阈值，不推断真实手机吞吐量。
5. 完整 unittest、编译、隔离 GUI 与打包 smoke；安装包／ZIP 校验；更新前确认空闲，备份真实配置并保持内容、基线和自启设置不变。
